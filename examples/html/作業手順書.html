1手順 1: 事前確認

現行サーバの稼働状態とバックアップの取得状況を確認する。

systemctl status app-server
ls -lh /backup/latest

確認事項

バックアップが当日分でない場合は、この時点で中止し責任者に連絡する。

2手順 2: サービス停止

sudo systemctl stop app-server
sudo systemctl stop batch-runner

3手順 3: 切替

DNS の向き先を新サーバに変更する。

sudo /opt/tools/switch-target.sh --to new-cluster

4手順 4: 疎通確認

確認項目 期待値 状態
ヘルスチェック 200 OK 未着手
バッチ起動 正常終了 未着手

切戻し手順

切戻し手順

疎通確認で異常が出た場合は、以下を実施して現行サーバに戻す。

sudo /opt/tools/switch-target.sh --to current-cluster
sudo systemctl start app-server
